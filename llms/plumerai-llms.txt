# Plumerai

> Plumerai builds AI software for intelligent cameras, combining tiny on-device edge AI models with cloud Vision Language Models (VLMs). Products include person/vehicle/animal/package detection, Familiar Face Identification, cross-camera Re-Identification, noise-robust motion detection, VLM-based video search and custom AI notifications, plus the Plumerai Inference Engine — a deep-learning model compiler and runtime optimized for CPU inference on Arm Cortex-M / Cortex-A, RISC-V and x86_64. Plumerai exposes SDKs (C++, C, Python, Rust, Java) rather than a hosted REST API; the same unified API runs identically from microcontrollers to servers.
